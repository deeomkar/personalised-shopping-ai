# MyShop

A native JavaFX shopping assistant with personalized product search and recommendations.

## Requirements

- JDK 25+
- Maven 3.x
- Git

## Setup

```bash
git clone https://github.com/deeomkar/personalised-shopping-ai.git
cd personalised-shopping-ai
mvn clean compile
```

## Run

```bash
mvn javafx:run
```

## Test

```bash
mvn clean test
```
